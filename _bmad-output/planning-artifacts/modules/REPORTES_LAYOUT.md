# Layout Detallado: Reportes Analíticos (Business Intelligence)
**Versión:** 1.0
**Plataformas:** Desktop (Deep Dive) & Mobile (Resumen Ejecutivo)

## 1. Dashboard de Salud Financiera (Desktop)
*   **Gráficos Principales:**
    *   **Ventas vs Costos:** Gráfico de áreas para ver el margen neto mensual.
    *   **Top 5 Productos:** Gráfico de torta por volumen de utilidad.
    *   **Cuentas por Cobrar:** Listado cronológico de deudas vencidas.
*   **Filtros:** Por fecha, sucursal, categoría de producto y vendedor.

---

## 2. Reporte de Rotación de Inventario (Desktop)
*   **Matriz de Análisis:**
    *   **Estrellas:** Alta rotación, alta utilidad.
    *   **Dormidos:** Baja rotación, alta utilidad.
    *   **Huesos:** Baja rotación, baja utilidad.
*   **Sugerencia IA:** "Recomendamos liquidar el stock de [Producto X] para liberar flujo de caja."

---

## 3. Resumen Ejecutivo de Bolsillo (Mobile)
*   **Visual:** Tarjetas verticales con KPIs clave del día:
    *   "Ventas totales hoy: $1,240 (↑ 15% vs ayer)".
    *   "Margen de utilidad: 28%".
    *   "Stock crítico: 3 productos por agotarse".
*   **Acción:** Botón para "Compartir PDF de Cierre" por WhatsApp/Email.
