# Layout Detallado: Onboarding y Registro (90 Días Trial)
**Versión:** 1.0
**Plataformas:** Desktop & Mobile (Celular)

## Pantalla 1: Registro Inicial (The Gateway)
**Desktop:**
*   Imagen lateral inspiradora (Comercio moderno).
*   Formulario central: Email, Nombre de Empresa, RIF.
*   Botón "Comenzar mi prueba de 90 días" (Color primario: Azul vibrante).

**Mobile:**
*   Layout vertical simplificado.
*   Enfoque total en el formulario para evitar distracciones.
*   Teclado numérico automático al tocar el campo RIF.

---

## Pantalla 2: Configuración de "Soberanía Económica"
**Experiencia Dual:**
*   Selector visual: "¿Deseas usar la tasa oficial BCV?" (Switch: On/Off).
*   Si es Off: Campo para ingresar tasa personalizada.
*   Selector de Moneda Base: VES o USD.
*   Mensaje: "No te preocupes, puedes cambiar esto en cualquier momento."

---

## Pantalla 3: Carga de Primer Producto (The "Aha!" Moment)
**Desktop:**
*   Zona de "Drop" para archivos Excel.
*   Grid de carga manual rápida.

**Mobile (Celular):**
*   Botón flotante "Escanear Código de Barras".
*   Al escanear, el sistema busca en una base global o abre el formulario pre-llenado.
*   Campos mínimos: Nombre, Precio, Stock Inicial.

---

## Pantalla 4: Dashboard de Bienvenida
**Experiencia Dual:**
*   Banner de Sandbox (Ámbar): "Modo de Prueba Activado. Tienes 90 días de acceso total."
*   Tarjeta central: "Tu siguiente paso: Realiza tu primera venta de prueba."
*   Botón gigante: "IR AL PUNTO DE VENTA (POS)".
